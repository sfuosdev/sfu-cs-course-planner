# Contributing to SFU CS Course Planner

Thanks for contributing to the SFU OS DEV student project.

## Contribution workflow

1. Fork the official SFU OS DEV repository.
2. Clone your fork locally.
3. Create a feature branch.
4. Make your changes and run tests.
5. Commit and push your branch.
6. Open a Pull Request to the official repository.
7. Address review feedback before merge.

## Branch naming examples

- `feature/course-search`
- `feature/prerequisite-checker`
- `fix/api-error`
- `docs/update-readme`

## Local checks before submitting

- Backend tests: `cd backend && pytest`
- Frontend tests: `cd frontend && npm test`
- Frontend build: `cd frontend && npm run build`
