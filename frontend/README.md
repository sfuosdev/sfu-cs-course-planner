# Frontend

The frontend is a React and TypeScript single-page application built with Vite.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Run locally

```bash
npm install
npm run dev
```

Vite prints the local development URL in the terminal (usually
`http://localhost:5173`).

## Available scripts

- `npm run dev` starts the development server.
- `npm run build` type-checks the app and creates a production build in `dist/`.
- `npm run preview` serves the production build locally.
- `npm run lint` runs Oxlint.

Source code lives in `src/`, with planned areas for reusable components, pages,
and API services.
